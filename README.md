# Car Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing car sales data using Power BI. An interactive dashboard was developed to understand sales performance, identify trends, and analyze business performance across different car companies, body styles, colors, and dealer regions.

## Dashboard Pages

### 1. Overview Dashboard
- YTD Total Sales
- YTD Average Price
- YTD Cars Sold
- Weekly Sales Trend
- Sales by Body Style
- Sales by Color
- Cars Sold by Dealer Region
- Company-wise Sales Performance

### 2. Details Dashboard
- Car ID
- Date
- Customer Name
- Dealer Name
- Company
- Color
- Model
- Total Sales

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Objectives
- Analyze overall car sales performance.
- Track year-to-date and month-to-date sales.
- Identify popular car body styles and colors.
- Compare sales performance across companies.
- Analyze dealer and regional sales performance.
